# gbdi.io

The website of the Global Building Data Initiative, www.gbdi.io.

It is being rebuilt from Framer as a static [Jekyll](https://jekyllrb.com)
site on GitHub Pages. Until the rebuild is signed off and the domain is
switched, www.gbdi.io is still served by Framer and nothing in this
repository is live.

## Where things are

| File | What it covers |
| --- | --- |
| `docs/01-rebuild-work-order.md` | Phase A work order: the like-for-like rebuild, step by step |
| `docs/content-issues.md` | Things noticed on the live site but deliberately not changed in Phase A |
| `AGENTS.md` | How to work in this repository: ground rules, pull requests, who merges |

How to run the site locally and how to edit text, team, partners and the FAQ
will be written here once the site exists (step 3 of the work order).
